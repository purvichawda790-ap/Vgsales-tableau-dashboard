 Video Game Sales Dashboard - Tableau Project

 Project Overview

This project presents an interactive Tableau dashboard created to analyze global video game sales data across different platforms, genres, publishers, and regions. The dashboard provides meaningful insights into sales trends, top-performing platforms, and market performance using data visualization techniques.

 Tools & Technologies Used

* Tableau Public
* Excel / CSV Dataset

 Dashboard Features

* Dynamic filters for interactive analysis
* KPI cards for quick insights
* Sales analysis by platform and genre
* Regional sales comparison
* Bubble chart, treemap, bar chart, and trend visualization

 Key Insights

* Action genre generated the highest sales globally
* North America contributed the largest share of sales
* Popular gaming platforms showed consistent market dominance
